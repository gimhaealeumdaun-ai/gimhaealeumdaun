# 부산 아파트 통계보드

국토교통부 실거래가로 본 부산 아파트 매매·전세·월세 대시보드입니다. 구·동과 기간을 고르면 화면 전체가 바뀌고, 단지·학교·역 이름을 검색하면 위치 미리보기와 Google 지도 팝업, 단지 시세·입지 분석을 볼 수 있습니다.

## 들어 있는 것

- 주간 매매·전세 가격지수(실거래가 4주 이동 중앙값, 2026.01.12 주 = 100)와 주간 변동률
- 구·동별 최근 4주 평당가 상승률 순위, 주간 평균가격
- 3.3㎡당 시세 상승 단지 TOP, 단지 TOP 10(거래가·평당가·거래량)
- 월간 거래 유형 비중, 매매가격대 분포, 월간 거래량, 전세가율
- 단지·학교·역 검색과 위치 미리보기, 단지 시세 요약과 입지 분석(학군·지하철·KTX·동해선)
- 한국부동산원 부산 매매가격지수

## 실행

정적 파일만으로 돌아갑니다. 브라우저가 `data/` 폴더의 파일을 읽기 때문에 로컬에서는 간단한 웹 서버로 여세요.

```bash
python3 -m http.server 8765
```

그다음 http://localhost:8765 를 엽니다. GitHub Pages에서는 저장소 루트를 그대로 배포하면 됩니다.

## 데이터와 출처

| 파일 | 내용 | 출처 |
|---|---|---|
| `data/trades.csv` | 아파트 매매 실거래 57,302건 (2025.01~2026.10 계약, 해제 거래 제외) | 국토교통부 아파트 매매 실거래가(공공데이터포털) |
| `data/rents.csv` | 아파트 전월세 실거래 98,946건 (2025.01~2026.10 계약) | 국토교통부 아파트 전월세 실거래가(공공데이터포털) |
| `data/complexes.csv` | 거래 단지 4,140곳 목록과 그중 약 660곳의 위치 | 단지 이름을 OpenStreetMap(ODbL) 단지 이름과 맞춰 찾음 |
| `data/poi.csv` | 도시철도·동해선·KTX 역, 초·중·고등학교 위치 | © OpenStreetMap 기여자, ODbL |
| `data/gu_shapes.json` | 부산 16개 구·군 경계(단순화) | 통계청 2013년 행정경계, southkorea-maps |
| `data/price_index.csv` | 부산 아파트 매매가격지수 2026년 3~8월 | 한국부동산원 R-ONE |

자료는 2026년 10월 30일에 받았습니다. 실거래는 계약 후 30일 안에 신고되므로 최근 한 달은 건수가 덜 잡혀 있습니다.

## 계산 방법

- 평당가는 전용면적 3.3058㎡ 기준입니다. 공급면적 기준인 다른 통계보다 높게 나옵니다.
- 월세의 평당가는 보증금에 연 월세를 전환율 연 6%로 나눈 금액을 더한 전세 환산 보증금으로 계산했습니다.
- 가격지수는 시세 조사가 아니라 실거래가로 계산해, 그 주에 어떤 단지가 거래됐는지에 따라 흔들립니다.

참고용 자료이며 매수·매도 판단의 기준으로 쓰지 마세요.
